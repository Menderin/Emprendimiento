
# AGENTS.md — TaskU

## Contexto del proyecto

TaskU es un prototipo académico de una plataforma que conecta estudiantes que necesitan resolver tareas puntuales con otros estudiantes que pueden realizarlas.

La descripción completa de la idea, los requisitos y el flujo esperado se encuentran en:

**`Docs/idea.md`**

## Instrucciones para agentes

1. Leer `Docs/idea.md` antes de comenzar cualquier desarrollo.
2. Utilizar ese documento como fuente principal de requisitos.
3. Mantener la implementación simple, clara y funcional.
4. Utilizar HTML, CSS y JavaScript puro, sin frameworks.
5. Almacenar los datos localmente mediante `localStorage` en formato JSON.
6. Priorizar el flujo completo entre solicitante y prestador.
7. No implementar funcionalidades fuera del alcance sin justificación.
8. Mantener el código organizado, legible y fácil de modificar.

## Objetivo

Construir un prototipo funcional y demostrable de TaskU, no una aplicación lista para producción.

Ante cualquier ambigüedad, consultar `Docs/idea.md` y preferir la solución más sencilla que cumpla los requisitos.
