# TaskU

Prototipo académico para conectar estudiantes de la UCN, campus Guayacán. Implementado con HTML, CSS y JavaScript puro, sin dependencias.

## Abrir el prototipo

Abre `index.html` en un navegador moderno. No requiere instalación ni servidor. Las tareas y postulaciones se guardan como JSON en el `localStorage` del navegador; utiliza el mismo navegador y ubicación del archivo durante la demostración.

## Demostración (1–2 minutos)

1. En **Necesito ayuda**, publica una tarea o usa el ejemplo del SSD.
2. Cambia a **Ofrecer mis habilidades** y selecciona **Camila R.**.
3. Abre el detalle y pulsa **Postular al trabajo**.
4. Selecciona **Matías P.** y postula a la misma tarea para comparar dos perfiles.
5. Vuelve a **Necesito ayuda**, abre la tarea y contrata a un postulante.
6. Cambia al modo prestador y elige al contratado: verás **Trabajo asignado**.
7. Opcionalmente, vuelve al solicitante y marca la tarea como completada.
8. Usa **Restablecer demo** para recuperar el ejemplo inicial.

Los perfiles, comentarios, reputación y verificación universitaria son ficticios. No hay autenticación real, pagos ni backend. Los requisitos están en `Docs/idea.md`.
